# ALIEN-SHIPS!

Work in progress project, endless bullet hell made in Raylib.

## Download
https://parsleyjoe.itch.io/alien-ships

# Building

Cmake Project, build by:

```
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DPRODUCTION_BUILD=ON
cmake --build build/
```

Linux and Mac not supported, may work on them but not tested.
